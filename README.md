# Crescent Developments — Luxury Real Estate Web Experience

A cinematic, award-winning luxury residential real estate web application built with **React 19**, **Vite**, **Tailwind CSS v4**, and **GSAP ScrollTrigger**.

## Key Features

- **Exterior Curtain Reveal**: High-impact architectural exterior hero with GSAP smooth curtain lift-up effect on scroll.
- **Cinematic 30fps Scroll-Based Interior Walkthrough**: High-fidelity scroll-synchronized canvas animation through the Living Hall and Dining Area without any obstructive overlays.
- **Floating Optical Contrast Typography**: Multi-tiered optical text shadows that stay crisp and readable over any interior lighting angle.
- **Sequential Collections Reveal**: Pinned dusk architectural visual featuring **Luxury Residences**, **Urban Living**, and **Waterfront Homes** revealed sequentially as the user scrolls.
- **Interactive Portfolio Catalog**: Comprehensive modal filtering system across developments, specifications, pricing, and completion timelines.
- **Inquiry & Sales Concierge**: Fully integrated modals for scheduling private viewings and downloading brochures.
- **Full Mobile Responsiveness**: Precision-crafted touch targets, horizontal tab swiping, fluid layouts, and zero-error viewport scaling across mobile, tablet, and desktop.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Animation Engine**: GSAP 3 + ScrollTrigger
- **Icons**: Lucide React

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vishalbalasaani/real-estate.git
   cd real-estate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
```
Build output is generated in `/dist` and ready for immediate deployment to Vercel, Netlify, or any static hosting provider.
